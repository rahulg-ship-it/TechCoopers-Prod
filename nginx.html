Jab browser kisi website ko request karta hai, to request pehle NGINX ke paas aati hai. NGINX phir: nginx architecure me ek master process chal rhi hoti hai, jo bahut sari child process bnakar rkti hai, and when user comes to our site, it treats like one child-process, then second user treats like different second child process. nginx architecture me chhoti chooti child proceses ya worker processes chal rhi hoti hai and uski vajah se aapka load distrubute ho jata hai. static files directly serve karta hai ya request backend application (PHP, Node.js, Python etc.) ko forward karta hai. MAIN USES OF NGINX - SERVE WEBSITE, One nginx can host MANY websites.
